## 疯狂的世界生成 数据包

分两个版本：

高倍率噪声  High-frequency noise

低倍率噪声  Low-frequency noise

　

#### 高倍率噪声修改内容： 

整个世界都变得像边境之地那样破碎

核心修改就是把所有噪声的输出的比例因子进行修改

1.绝大部分噪声的输出的比例因子翻了十倍，为避免观感过糟，涉及到恶地高度和冰刺高度的噪声翻了三倍 

2.树木的高度更加疯狂 

3.所有生物群系的平均距离缩短60%，主世界要塞的每环宽度减少60%，且生成次数增加到256次 

4.村庄生成范围增大 

5.生物群系的深度参数也变成了噪声随机，这样能看到在深板岩生长的珊瑚，出现在地上的深暗之域 

6.所有生物群系不再改变天空颜色

7.蘑菇岛不会自然生成

8.堡垒遗迹、下界化石和末地城加入主世界

9.绝大部分主世界生物群系的生成范围都改成了整个世界

10.视觉上的昼夜颠倒，与光照/天空光照绑定的机制会变，与时刻绑定的机制不变。
